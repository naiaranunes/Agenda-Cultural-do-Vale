
## 📌 Introdução

O projeto consiste no desenvolvimento de um sistema web para cadastro e divulgação de eventos culturais do Vale do São Francisco.

A proposta é criar uma plataforma simples que permita centralizar informações sobre eventos culturais da região, facilitando o acesso da população a essas atividades.


---

## 🎯 Objetivo

Facilitar o acesso da população aos eventos culturais locais, promovendo a valorização da cultura regional e incentivando a participação da comunidade.

---

## 💡 Motivação

A motivação para o desenvolvimento deste projeto é contribuir para a divulgação da cultura local, ajudando moradores e visitantes a encontrarem com mais facilidade eventos culturais na região do Vale do São Francisco.
